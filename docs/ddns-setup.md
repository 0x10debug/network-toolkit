# DDNS Setup Guide

Dynamic DNS (DDNS) keeps your domain pointing to your VPS even when the VPS IP changes.

## When You Need DDNS

- Your VPS has a dynamic IP (common with some providers)
- Your home internet has a dynamic IP and you're running services there
- You want automatic DNS updates instead of manually editing records

## Supported Providers

[ddns-go](https://github.com/jeessy2/ddns-go) supports:

| Provider | Notes |
|---|---|
| Cloudflare | Most recommended — free, fast API |
| Aliyun | Good for China-based servers |
| Tencent Cloud | Alternative for China |
| DNSPod | Tencent-owned, popular in China |
| Huawei Cloud | For Huawei Cloud DNS |
| Baidu Cloud | For Baidu Cloud DNS |
| Callback | Custom webhook for unsupported providers |

## Quick Start

### Step 1: Deploy the full-stack template

```bash
mb net deploy full-stack

# Enter:
# PRIMARY_DOMAIN=example.com
# FRP_TOKEN=<auto-generated>
# DDNS_TOKEN=your-cloudflare-api-token
```

This deploys Caddy + frp + ddns-go.

### Step 2: Access ddns-go web UI

ddns-go runs on port 9876. Access it via SSH tunnel or add a Caddy route:

```bash
# Option 1: SSH tunnel (temporary)
ssh -L 9876:localhost:9876 user@your-vps

# Then open: http://localhost:9876

# Option 2: Caddy route (permanent)
mb net proxy add ddns.example.com ddns-go:9876
```

### Step 3: Configure DDNS in the web UI

1. Select your DNS provider (e.g., Cloudflare)
2. Enter your API token
3. Add domains to update (e.g., `example.com`, `*.example.com`)
4. Set update interval (5 minutes is recommended)
5. Save

ddns-go will now automatically update your DNS records whenever your IP changes.

## Getting a Cloudflare API Token

1. Go to Cloudflare Dashboard → My Profile → API Tokens
2. Create Token → "Edit zone DNS" template
3. Zone Resources: Include → Specific zone → your domain
4. Continue to summary → Create Token
5. Copy the token — this goes in `DDNS_TOKEN`

## Manual Configuration

If you prefer config file over web UI, use the template in `components/ddns/ddns-go.example.yaml`:

```yaml
provider: cloudflare
token: "YOUR_API_TOKEN"
domains:
  - "example.com"
  - "*.example.com"
ipv4:
  enable: true
  url: "https://api.ipify.org"
interval: 5
```

## IPv6 Support

ddns-go supports IPv6. Enable it in the web UI or config:

```yaml
ipv6:
  enable: true
  url: "https://api6.ipify.org"
```

## Troubleshooting

### DNS not updating
- Check ddns-go logs: `docker logs ddns-go`
- Verify the API token has correct permissions
- Verify the domain exists in your DNS provider
- Check if the IP detection URL works: `curl https://api.ipify.org`

### Wrong IP detected
- If behind a NAT, use a public IP detection URL (not interface-based)
- For IPv6, ensure your VPS has a global IPv6 address
